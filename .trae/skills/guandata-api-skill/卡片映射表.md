# 观远卡片映射表

> 本文档用于记录 pageid 和 cardid 的对应关系，方便通过文档名称快速获取对应 ID 进行数据查询

## 基础信息

- **业务域名 (baseUrl)**: `https://bi.leyopharm.com`
- **文档域名**: `https://api.guandata.com`

## 登录信息（固定配置）

```json
{
  "domain": "guanbi",
  "loginId": "LY010307",
  "password": "eUlGNnBhX2c="
}
```

**说明**：
- `domain`: 观远平台域名标识
- `loginId`: 用户登录 ID
- `password`: Base64 编码的密码

## 卡片映射列表

| 文档名称/描述 | Page ID | Card ID | 备注 |
|--------------|---------|---------|------|
| 示例卡片 | - | `qd529d9dd687748ccb8c9f34` | 测试用卡片，已验证可用 |

## 使用说明

当需要获取某个卡片的数据时：

1. 在此表中查找对应的 Card ID
2. 使用以下参数调用观远 API：
   - `baseUrl`: `https://bi.leyopharm.com`
   - `domain`: `guanbi`（已配置）
   - `loginId`: `LY010307`（已配置）
   - `password`: `eUlGNnBhX2c=`（已配置）
   - `cardId`: 从上表获取

## API 调用示例

### 获取卡片数据（表格视图）

```bash
python .trae/skills/guandata-api-skill/scripts/guandata_two_step.py ^
  --base-url "https://bi.leyopharm.com" ^
  --domain "guanbi" ^
  --login-id "LY010307" ^
  --password "eUlGNnBhX2c=" ^
  --type card ^
  --card-id "qd529d9dd687748ccb8c9f34" ^
  --view GRID
```

### 获取卡片数据（图表视图）

```bash
python .trae/skills/guandata-api-skill/scripts/guandata_two_step.py ^
  --base-url "https://bi.leyopharm.com" ^
  --domain "guanbi" ^
  --login-id "LY010307" ^
  --password "eUlGNnBhX2c=" ^
  --type card ^
  --card-id "qd529d9dd687748ccb8c9f34" ^
  --view GRAPH
```

### 自定义请求体

```bash
python .trae/skills/guandata-api-skill/scripts/guandata_two_step.py ^
  --base-url "https://bi.leyopharm.com" ^
  --domain "guanbi" ^
  --login-id "LY010307" ^
  --password "eUlGNnBhX2c=" ^
  --type card ^
  --card-id "qd529d9dd687748ccb8c9f34" ^
  --body "{\"view\":\"GRID\",\"offset\":0,\"limit\":20}"
```
