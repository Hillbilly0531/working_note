# 测试验证文档（更新版）

> 文档版本：v2.0
> 更新时间：2026-04-17
> 适用范围：Flink CDC MySQL -> Elasticsearch 同步链路验证

## 1. 测试目标

确认三件事：
- 能启动
- 能同步
- 异常时能定位

## 2. 前置条件

- JDK 8、Maven 3.8+
- Nacos 配置可访问
- MySQL binlog 条件满足（`log_bin=ON`、`ROW`）
- ES 可写

## 3. 基础验证

### 3.1 编译与打包

```bash
mvn clean test
mvn clean package
```

预期：构建成功，产物在 `target/solar-openapi.jar`。

### 3.2 启动检查

```bash
java -jar target/solar-openapi.jar
```

预期日志包含：
- `[CDC_BOOT] Submit job`
- `CDC Runner MySQL Source 创建完成`
- `开始启动 CDC Job`

### 3.3 健康检查

```text
http://127.0.0.1:24051/actuator/health
```

预期：状态为 `UP`。

### 3.4 启动诊断单测

目标：确认启动阶段诊断逻辑能正确记录阶段名和耗时。

对应测试类：
- `src/test/java/com/leyo/cdc/job/CdcStartupDiagnosticTest.java`

验证点：
- `markPhase` 后阶段名更新正确
- 阶段耗时 `phaseElapsedMs` 会按新阶段重新计时
- 总耗时 `totalElapsedMs` 连续累加

## 4. 数据同步验证

1. 在 MySQL 目标表执行 `INSERT` / `UPDATE`
2. 在 ES 索引查询对应文档
3. 对照主键检查内容一致性

说明：当前实现默认不处理 `DELETE` 到 ES 删除。

## 5. 异常场景建议

- MySQL 断连：确认报错能指向连接失败
- ES 不可达：确认 sink 初始化或 bulk 阶段有清晰错误
- 配置缺失：确认能在启动日志里定位到具体 Job
