### 4.2 方式一：DataStream API开发

```java
import org.apache.flink.streaming.api.environment.StreamExecutionEnvironment;
import com.ververica.cdc.connectors.mysql.source.MySqlSource;
import com.ververica.cdc.debezium.DebeziumSource;
import org.apache.flink.connector.elasticsearch.sink.ElasticsearchSink;
import org.apache.flink.connector.elasticsearch.sink.ElasticsearchEmitter;
import org.apache.flink.formats.json.JsonFormatSerializationSchema;
import io.debezium.data.Envelope;
import org.apache.kafka.connect.json.JsonConverter;
import org.apache.kafka.connect.source.SourceRecord;

public class MySQLToElasticsearch {
    public static void main(String[] args) throws Exception {
        StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();
        env.enableCheckpointing(30000);

        // MySQL CDC Source配置
        MySqlSource<String> mySqlSource = MySqlSource.<String>builder()
            .hostname("192.168.27.54")
            .port(3306)
            .username("root")
            .password("Leyo@2022")
            .databaseList("your_database")      // 要同步的数据库
            .tableList("your_database.users")    // 要同步的表
            .deserializer(new JsonDebeziumDeserializationSchema())  // 使用JSON解析CDC数据
            .build();

        // Elasticsearch Sink配置
        ElasticsearchSink.Builder<String> esSinkBuilder = ElasticsearchSink.<String>builder()
            .setHosts(new HttpHost("192.168.27.55", 19200, "http"))
            .setConnectionUsername("elastic")
            .setConnectionPassword("leyo@@2021")
            .setEmitter(new ElasticsearchEmitter())
            .setBulkFlushMaxActions(1000)
            .setBulkFlushInterval(5000);

        // 添加sink
        env.fromSource(mySqlSource, WatermarkStrategy.noWatermarks(), "MySQL CDC Source")
           .sinkTo(esSinkBuilder.build());

        env.execute("MySQL to Elasticsearch CDC");
    }
}
```

## 六、经验总结

### 6.1 MySQL CDC配置要点
1. ✅ **binlog必须开启**：CDC的核心原理就是监听binlog变化
2. ✅ **binlog_format必须是ROW**：Statement模式无法准确追踪数据变更
3. ✅ **server_id必须唯一**：同一集群中每个MySQL实例都需要不同的server_id
4. ✅ **用户权限要正确**：需要REPLICATION相关权限

### 6.2 Elasticsearch CDC配置要点
1. ⚠️ **非标准端口**：19200端口，需要在连接配置中明确指定
2. ⚠️ **用户名密码认证**：ES 7.x/8.x默认开启X-Pack安全认证
3. ⚠️ **索引mapping匹配**：建议手动创建匹配的mapping，避免自动推断失败
4. ⚠️ **bulk写入优化**：设置合理的bulk size，提高写入性能

### 6.3 Flink CDC开发要点
1. ⚠️ **版本匹配**：CDC连接器版本需要与Flink版本匹配
   - Flink 1.20.1 → flink-connector-mysql-cdc 2.4.0
2. ⚠️ **反序列化器选择**：CDC数据有Debezium格式，选择合适的deserializer
3. ⚠️ **启动模式**：
   - `initial`: 全量同步 + 增量
   - `latest-offset`: 仅增量
   - `specific-offset`: 从指定位置开始

### 6.4 常见错误
1. `CDC user requires REPLICATION CLIENT privilege`：需要授予REPLICATION CLIENT权限
2. `Unknown system variable 'binlog_rows_query_log_events'`：MySQL版本太旧，移除该配置
3. `The slave is connecting using CHANGE MASTER TO`：server_id冲突或权限不足
4. `Connection refused`：检查ES端口19200是否正确，ES是否允许外部访问
5. `authentication failed`：检查ES用户名elastic和密码是否正确
