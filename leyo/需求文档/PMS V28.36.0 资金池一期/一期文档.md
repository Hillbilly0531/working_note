# 需求背景

集采控销业务，供应商给到乐药的费用除返利（正常返利、预收返利、集采代收）外，还有非返利（营销费、其他）的部分。当前非返利的申请审核动作均在OA，未与PMS打通，导致部分营销费被子公司当初返利费用使用。故希望可以在PMS进行统一管理。

**备案类型**

**说明**

备案

外部引入

主要指战略厂牌事业部从外部厂牌引入资金的备案流程。需要上传发票/银行流水，并冻结返利凭证对应金额，生成一条认领记录。（若收款公司是集团则无需触发冻结）

包含资金来源明细和计划使用明细。

- **资金来源明细**：凭证明细
- **使用计划明细**：资源归属部门+项目+金额

eg：若厂牌商务备案金额里需要划拨一部分给到运营中心进行营销使用，可以在备案时新增一条计划使用明细，资源归属部门选择运营中心。

- 仅可对符合账号关联的“厂牌”进行备案

内部分配

主要指摇钱树事业部从外部厂牌引入资金的备案流程。由于摇钱树涉及的银行流水通常非常零碎，故不强制要求上传发票/银行流水，通常会上传清单附件说明资金明细，不涉及返利凭证冻结。

包含资金来源明细和计划使用明细。

- **资金来源明细**：内部分配清单（附件）
- **使用计划明细**：资源归属部门+项目+金额

年度预算

主要指运营中心虚拟预算的备案流程，金额备案给运营中心各个小组资金池。虽有实际流水，但系统上没有发票/银行流水，也不涉及冻结。

- 仅可对符合账号关联的“运营池”进行备案

备案作废

/公共说明/

对已备案可使用金额进行作废。若是外部引入，还涉及返利凭证解冻。

- 仅备案人可操作。

调配

/公共说明/

对已备案可使用金额进行调配。即：修改计划使用明细的“资源归属部门+项目+金额”。

- 仅备案人可操作。

使用

/公共说明/

对已备案可使用金额进行使用。一次仅可使用一个备案单中的可使用金额。

- 外部引入、内部分配：仅符合账号关联的“资源归属部门”+“厂牌池”权限的备案单可选。
- 年度预算：仅符合账号关联的“运营池”权限的备案单可选。

核销

/公共说明/

对已使用可核销金额进行核销。若是外部引入，还需在返利凭证生成一条核销记录。

- 仅使用人可操作。

流程现状参考：

①资源归属主体是【战略厂牌事业部】时，

- 备案审批流：商务发起—所属上级(审批)--内管（嘉茹，伟珊）-乐药财务预算岗（罗芷莹）—战略厂牌事业部负责人，抄送-乐药集团总经理、乐药财务总监
- 使用审批流&核销审批流：所属上级(审批)-集采内管（嘉茹，审批）-cc集采内管（伟珊）-乐药总部财务预算岗—战略厂牌事业部负责人—乐药总部财务总监—乐药集团总经理-商务运营（媚淇处理，类似OA归档）+CFO(＞100-300)+CEO(≥300+)

②资源归属主体是【运营中心】时，

- 备案审批流：申请人--乐药财务预算岗（刘昕）--所选资源归属管理部门的部门负责人
- 使用审批流：运营发起—运营归属组长—乐药总部财务预算岗（刘昕）—乐药总部资源归属部门负责人（黄晓东）—乐药总部财务总监—乐药集团总经理+CFO(＞100-300) +CEO(≥300+)
- 核销审批流：运营发起—运营归属组长—乐药总部财务预算岗（刘昕）—乐药总部资源归属部门负责人（黄晓东）+CFO(＞100-300)+CEO(≥300+)

③资源归属主体是【摇钱树】时，

- 备案审批流：申请人--乐药财务预算岗（唐源萍）--所选资源归属管理部门的部门负责人
- 使用审批流：乐药总部财务预算岗（唐源萍）--乐药总部资源归属部门负责人--乐药总部财务总监--乐药集团总经理+CFO(>100-300)+CEO(2300+)
- 核销审批流：乐药总部财务预算岗（唐源萍）--乐药总部资源归属部门负责人
