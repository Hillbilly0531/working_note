# 1.【一块】按采购金额，兼容一块方案

一块医药【按采购金额 - 普通型】支持配置【计退规则】，并根据配置对应不同返利计算逻辑。

# 2. 功能说明

入口：返利管理（新）-返利协议，【按采购金额-普通型】协议，新增、修改、查看详情

## 2.1. 按采购金额-普通型

### 2.1.1. 限制类型

![](https://file.tapd.cn/compress/compress_img/1400/tapd_40013426_base64_1776918122_730.png?src=/tfl/captures/2026-04/tapd_40013426_base64_1776918122_730.png "点击看原图")

选中【普通型】，显示计退规则设置

> [!note] 仅一块
> 计退规则仅适用于一块医药。

- **计退规则**
  - 单选，必选，交互样式同系统公共样式；
  - 可选项：不计退、计退；
  - 默认选中：不计退；
  - 显示帮助提示，交互样式同系统公共样式，提示内容如下：
    - 不计退：计算阶梯、返利时不会减去采退/销退数据；
    - 计退：计算阶梯、返利时按减去采退/销退数据算；

# 2.【一块】按采购数量，兼容一块方案

# 1. 概述

【按采购数量 - 普通型】支持配置【计退规则、返利规则】，并根据配置对应不同返利计算逻辑。

# 2. 功能说明

入口：返利管理（新）-返利协议，【按采购数量-普通型】协议，新增、修改、查看详情

## 2.1. 按采购数量-普通型

### 2.1.1. 限制类型

![](https://file.tapd.cn/compress/compress_img/1400/tapd_40013426_base64_1776928047_885.png?src=/tfl/captures/2026-04/tapd_40013426_base64_1776928047_885.png "点击看原图")

- 选中【普通型】，显示【计退规则】设置

> [!note] 仅一块
> 计退规则仅适用于一块医药。

  - 单选，必选，交互样式同系统公共样式；
  - 可选项：不计退、计退；
  - 默认选中：不计退；
  - 显示帮助提示，交互样式同系统公共样式，提示内容如下：
    - 不计退：计算阶梯、返利时不会减去采退/销退数据；
    - 计退：计算阶梯、返利时按减去采退/销退数据算；

- 选中【普通型】，显示【返利规则】设置

> [!info] 一块 & 非一块
> 返利规则同时适用于一块医药和非一块医药。

  - 单选，必选，交互样式同系统公共样式；
  - 可选项：每1件返利、每满 x 件返利；
  - 默认选中：每1件返利
  - 显示帮助提示，交互样式同系统公共样式，提示内容如下：
    - 每满 x 件返利：每满5件返利1元，订单数量为6，返利＝（6÷5)向下取整×1＝1元

### 2.1.2. 协议总体限制

> [!info] 一块 & 非一块
> 协议总体限制同时适用于一块医药和非一块医药。

除了《限制类型》选择【返利规则＝每满 x 件返利】，其余与系统当前配置方式一致；

选择【返利规则＝每满 x 件返利】时，设置各数量阶梯的【返利金额】需改造

![](https://file.tapd.cn/compress/compress_img/1400/tapd_40013426_base64_1777261847_855.png?src=/tfl/captures/2026-04/tapd_40013426_base64_1777261847_855.png "点击看原图")

不设置【每个返利金额】，改为设置【每满X】【返利金额】两列。

> [!warning] 入参互斥要求（避免保存失败）
> - 当【返利规则=每1件返利】时：仅传“每个返利金额”字段（后端字段：`rebatePrice`），禁止传 `perX`、`rebateAmount`。
> - 当【返利规则=每满X件返利】时：仅传 `perX`、`rebateAmount`，禁止传“每个返利金额”字段（`rebatePrice`）。
> - 该规则同时适用于【协议总体限制】与【返利商品限制】的每一条阶梯。

| 字段 | 说明 |
|------|------|
| **【每满X】** | |
| 表头帮助提示 | 交互样式同系统公共样式，提示内容：X＝5，订单数量为6，每满x件返利1元，返利＝（6÷5)向下取整×1＝1元 |
| 列表输入框 | 必填，仅支持＞0的整数；输入框失焦、点击【保存】等触发校验时，输入不合规按当前界面已有交互样式进行提示；输入不合规提示文案：仅支持＞0的整数 |
| **【返利金额】** | |
| 输入框 | 必填；仅支持＞0的数字，最多可输入2位小数点；提示文案：仅支持＞0的数字 |

### 2.1.3. 返利商品限制

> [!info] 一块 & 非一块
> 返利商品限制同时适用于一块医药和非一块医药。

除了《限制类型》选择【返利规则＝每满 x 件返利】，其余与系统当前配置方式一致；

选择【返利规则＝每满 x 件返利】的，设置各商品各数量阶梯的【返利金额】进行改造，改造同上《协议总体限制》

![返利商品限制截图](https://file.tapd.cn/compress/compress_img/1400/tapd_40013426_base64_1777261813_657.png?src=/tfl/captures/2026-04/tapd_40013426_base64_1777261813_657.png "点击看原图")
